# Naming: poweragents (working name)

**What it is.** A desktop app (macOS, Windows) that gives people who don't program an AI agent set up
the way developers set up their own: it works in their projects, browses, runs on schedules and keeps
a memory of them in plain files. Individuals first; money later from companies (shared team
workspaces). Product design: `docs/design/poweragents/`.
**Space.** Personal AI agents and assistants (Claude Cowork, OpenWork, ChatGPT agents, Lindy, etc.).
**Audience.** Non-technical people, including "AI native" chat users; later their companies.
**Languages.** English name; the app ships in Polish and English, so the name must also be easy for
Polish speakers. *(Inferred by the agent, not yet confirmed.)*
**TLDs.** Checked: .com, .app, .ai, plus `get<name>.com`. A bare `.app` or `get<name>.com` is
acceptable to the user (round 1) — a bare .com is not required. `.so` is fine; `.dev` is not — this
is a consumer product (round 8). Other consumer-friendly TLDs may be explored.

## What the name should make you feel

In the user's words (round 0): accessible, approachable, easy — and at the same time capability and
strength. "An agent that is very easy to use but gives you very large possibilities and really
changes how I work and how I live."

## Mascot (round 5)

The user wants branding built around a mascot that both shows what the app can do and animates
situations such as waiting for the agent's answer. Reference: OpenAI's simple, abstract "dots"
mascot. The name can be a first name or something else, as long as it fits a simple, animatable
mascot.

## Standing preferences

- `<name>.app` and `get<name>.com` are fine (round 1).
- Wants to explore unexpected directions beyond first names too (round 4).
- International feel preferred; Slavic is fine if foreigners can say and spell it easily (round 3).
- Wants human first names: coined ones that sound like real names, and a broader pool of real names (round 2).

- Open to the currently popular direction of a good-sounding human first name; the user's own ideas
  were Jerry and Jer (round 0).

- Liked Nib: "looks very promising" (round 6). What it shares — one short syllable, a tiny
  everyday object, the tip of a tool that does big work, easy to draw as a mascot. User clarified
  (round 7): it was the **short name with a punchy, catchy sound**, not the pen-tip meaning.

- Likes Neb and Zib (round 8): three letters, short vowel, punchy.
- A short name must sound complete in English: "Tez" sounds like it is missing a second z (round 8).

- Not only three-letter names: longer names are fine if they sound good (round 9).
- Wants to try names and surnames of famous people, e.g. scientists ("Edison", probably taken) (round 9).

- Wants coined first names, a bit longer: ideally two syllables, three at most (round 10).

- Avoid harsh consonant clusters mid-name: "Varlo sounds coarse because of that combination" (r+l), round 11.

- Oberon is "quite interesting", but don't fixate on it; keep looking for names (round 13).

- Sancho "sounds great" (sanch.io exists, keep it anyway); Camillo "also interesting" (round 14).
  Liked so far: Nib, Neb, Zib, Oberon, Sancho, Camillo.

- Alonso and Tancho "not bad" (round 15).
- Wants good-sounding names in an Italian / Spanish / Latin mix — not necessarily literary helpers
  (round 15).
- **Method, from the user:** check every name by searching "<name> ai" first — that is how the user
  found sanch.io and alonso.ai at once (round 15).

- Lupo is the current favourite (round 17). Lupo "is great" (round 16) — Italian 'wolf'; an animal name that doubles as a first name and a mascot.
- Ilario "quite OK", but would have to be written lowercase so the capital I is not read as l (round 16).
- Avoid names one vowel away from a famous name: "Amedeo gets confused with Amadeo" (round 16).

## Rejected directions

- Coined two-syllable names ending in -en/-in/-on/-an (Nebin, Tevon, Zavon…) — "why do they all end in -on, -in, -an, -en? Let's try another direction" (round 12).

- Literal Polish first names (Radek, Bronek, Franek, Olek) — "feel weird" (round 4).

- "Giant" compounds (Kind/Gentle/Easy/Pocket Giant) — "sounds weak" (round 2).

- "Power" names in the Power Rangers vein — "Power Agent" and similar are taken (round 0).
